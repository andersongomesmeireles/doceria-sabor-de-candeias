# Doceria Sabor de Candeias

Site de uma página feito em aula na UC Projeto de Front-End (SENAI Candeias, turma 92233), com HTML, CSS e JavaScript.

## Como baixar (clonar)

No terminal do VS Code:

```bash
git clone https://github.com/andersongomesmeireles/doceria-sabor-de-candeias.git
cd doceria-sabor-de-candeias
```

Depois, abra a pasta no VS Code e clique com o botão direito no `index.html` → **Open with Live Server**.

## Arquivos

```
doceria-sabor-de-candeias/
├── img/
│   ├── bolo.jpg
│   ├── brigadeiro.jpg
│   └── torta.jpg
├── index.html   → estrutura (HTML)
├── style.css    → aparência (CSS)
└── script.js    → ação (JS)
```

## O que o site faz

- Mostra o nome da doceria, o menu e 3 produtos com foto e preço.
- Mostra o horário e as regras de encomenda.
- No pedido: com o campo vazio, aparece "Digite seu nome, por favor." em vermelho; com o nome preenchido, aparece "Obrigado, [nome]! Seu pedido foi enviado." em verde.
- No celular, os produtos ficam um embaixo do outro.
